# Weapons

Weapons and hand-held tools/props, one folder per id, e.g. `BlacksmithHammer/`.
Static meshes: `SM_Weapon_<Id>.fbx`, `PF_Weapon_<Id>.prefab`, `T_<Id>_<Role>.png`, `M_<Id>.mat`, `ASSET_SOURCE.txt`.
Pivot at the grip point, +Y along the handle towards the head/blade (see the document).

Budget (proposal): <= 3k tris, 1 material, 1K textures.
Not to be confused with the METINAR-007 AR sword prototype, which this pipeline does not touch.
